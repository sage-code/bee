# TODO List

This directory contains individual Markdown files, where each file represents a distinct task or work item for the Bee language project. 

Each file corresponds to a task that should be tracked as a separate issue in the [GitHub repository](https://github.com/sage-code/bee).

To add a new task:
1. Create a new `.md` file in this directory with a descriptive name.
2. Outline the details of the task within the file.
3. Once the task is tracked on GitHub, it can be marked as in-progress or closed.
