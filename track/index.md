# Project Index: Bee Language

This file provides an index of the project for efficient AI agent management.

## Directory Structure
- `/demo`: Example code snippets for the Bee language.
- `/doc`: Legacy documentation (HTML).
- `/files`: Supplementary files (e.g., Notepad++ UDL configuration).
- `/img`: Images used in documentation.
- `/spec`: Current Markdown documentation (Source of Truth).
- `/todo`: Individual work item files.
- `/tools`: Utility scripts (e.g., `make-spec.py`).
- `/track`: Project management and AI synchronization files.

## Important Documentation
- `DECISIONS.md`: The authoritative log of all design decisions.
- `readme.md`: High-level project information.
- `SPEC.md`: Master specification file.

## Operational Rules
- Mandatory 30-second delay between file writes (enforced in `GEMINI.md`).
- All design decisions must be tracked via `DECISIONS.md` and corresponding `/todo` items.
- All agents must coordinate via `/track/status.md`.
